# Dead Internet Project

This project is inspired by the "Dead Internet Theory" - the idea that a significant portion of internet content and interactions could be AI-generated. It's a mini social network where comments are responded to by AI, creating an experimental environment to explore the boundaries between human and artificial interactions.

## Features
- User posts and comments
- AI-generated responses
- Simple social network interface
- Interaction analytics

## Libraries and Technologies Used

### Backend
- Go (Golang)
- Chi Router - HTTP router

More libraries will be added as the project develops.
